SPECACT — Vue 3 PWA для публикаций и фото, которыми вы делитесь **только с выбранными людьми**. У нас нет ни сервера, ни базы данных:

- Все данные хранятся в **папке `SPECACT` в вашем собственном Google Диске**.
- Кто видит запись, определяют **права доступа Google Диска**: нет прав — нет доступа, даже по ссылке.
- После загрузки браузер **общается только с Google** (CSP блокирует всё остальное). Веб-хост лишь отдаёт статические файлы.
- У каждого пользователя **свой Google OAuth-клиент**; ID/секрет клиента, токены и ключи не покидают устройство, **дважды зашифрованы** и защищены **6-значным PIN**.

## Персонально · Суверенно · Децентрализованно

- Суверенитет: данные в вашем Диске, посредника нет — ни один сервер проекта не может их хранить, читать или менять.
- Персонализация: вы решаете, кто видит, кто комментирует, какие записи под паролем или публичны по ссылке.
- Децентрализация: открытый формат позволяет многим сайтам и приложениям использовать один ваш источник личных данных.

## Возможности

- Записи: создание, правка, удаление; фото (уменьшение, удаление EXIF/GPS) и просмотр слайдами с масштабом и поворотом.
- Доступ: упоминания `@email`, роли «просмотр»/«комментарии», отзыв в любой момент.
- Публичная ссылка: «все, у кого есть ссылка» открывает только файлы записи, но не папку.
- Записи под паролем шифруются в браузере (AES-256-GCM).
- Режимы комментариев: открытый / только выбранные / закрытый — обеспечиваются в Drive. Лайки следуют за теми, кто видит запись.
- Быстрый личный индекс (index.json) с зашифрованным локальным кэшем.
- Дважды зашифрованное локальное хранилище, 6-значный PIN, автоблокировка, стирание после многих неверных попыток.
- 14 языков (включая RTL), светлая/тёмная тема, адаптивность, устанавливаемая PWA, демо `#/demo`, страницы «О проекте»/«Условия»/«Конфиденциальность».

## Быстрый старт

```bash
npm install
npm run dev            # http://localhost:5173
```

Для реального использования создайте свой Google OAuth-клиент (около 5 минут): docs/GOOGLE_SETUP.md. Для знакомства без настройки откройте `#/demo`.

## Docker

```bash
cp .env.example .env
docker compose up -d --build   # http://localhost:8088
```

- Соберите и запустите командой выше; порт меняется через `SPECACT_PORT` в `.env`.
- nginx без root, файловая система только для чтения, строгий CSP. Измените `.env` и выполните `docker compose up -d` — пересборка не нужна.
- Для реального домена используйте HTTPS (Google разрешает http:// только для localhost; WebCrypto требует безопасного контекста).
- Все настройки описаны в `.env.example`. Никогда не помещайте секрет Google-клиента в `.env`.

## Известные ограничения

- Логика Drive проверена на имитации Drive, а не на настоящем Google — сначала попробуйте на тестовом аккаунте.
- В режиме Testing refresh-токены Google живут 7 дней (войдите снова).
- Комментаторы технически могут править чужие комментарии через Drive; одновременные записи редко затирают друг друга.
- Отзыв доступа не отменяет увиденное; защита паролем сильна настолько, насколько силён пароль.
