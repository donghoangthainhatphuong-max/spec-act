SPECACT คือ PWA บน Vue 3 สำหรับ**แชร์โพสต์และรูปภาพกับคนที่คุณเลือกเท่านั้น** ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูลของเรา:

- ข้อมูลทั้งหมดอยู่ใน**โฟลเดอร์ `SPECACT` ใน Google ไดรฟ์ของคุณเอง**
- ใครเห็นโพสต์ได้ถูกกำหนดโดย**สิทธิ์ของ Google ไดรฟ์** — ไม่มีสิทธิ์ก็เข้าไม่ได้ แม้มีลิงก์
- หลังโหลดหน้า เบราว์เซอร์**คุยกับ Google เท่านั้น** (CSP บล็อกปลายทางอื่นทั้งหมด) โฮสต์เว็บแค่ส่งไฟล์สถิต
- ผู้ใช้แต่ละคนใช้ **Google OAuth client ของตัวเอง** รหัสไคลเอ็นต์/รหัสลับ โทเคน และคีย์ไม่ออกจากอุปกรณ์ **เข้ารหัสสองชั้น** และป้องกันด้วย **PIN 6 หลัก**

## ส่วนตัว · อธิปไตยข้อมูล · กระจายศูนย์

- อธิปไตยข้อมูล: ข้อมูลอยู่ในไดรฟ์ของคุณ ไม่มีผู้ให้บริการคั่นกลาง เซิร์ฟเวอร์ใดของโครงการก็เก็บ อ่าน หรือแก้ไขไม่ได้
- ปรับแต่งเอง: คุณกำหนดว่าใครเห็น ใครแสดงความเห็น โพสต์ไหนมีรหัสผ่านหรือเปิดสาธารณะด้วยลิงก์
- กระจายศูนย์: รูปแบบข้อมูลแบบเปิดทำให้หลายเว็บไซต์และแอปใช้แหล่งข้อมูลส่วนตัวของคุณร่วมกันได้

## ฟีเจอร์

- โพสต์: สร้าง แก้ไข ลบ รูปภาพ (ย่อขนาด ลบ EXIF/GPS) พร้อมตัวดูแบบสไลด์ (ซูม หมุน)
- การแชร์: แท็ก `@อีเมล` บทบาท “ดูได้”/“แสดงความเห็นได้” เพิกถอนได้ทุกเมื่อ
- ลิงก์สาธารณะ: “ทุกคนที่มีลิงก์” เปิดเฉพาะไฟล์ของโพสต์ ไม่เปิดโฟลเดอร์
- โพสต์ที่มีรหัสผ่านถูกเข้ารหัสในเบราว์เซอร์ (AES-256-GCM)
- โหมดความเห็น: เปิด / เฉพาะผู้ที่แชร์ให้ / ล็อก — บังคับใช้ใน Drive การกดถูกใจตามผู้ที่เห็นโพสต์ได้
- ดัชนีส่วนตัวที่รวดเร็ว (index.json) พร้อมแคชในเครื่องที่เข้ารหัส
- ห้องนิรภัยในเครื่องเข้ารหัสสองชั้น PIN 6 หลัก ล็อกอัตโนมัติ ลบเมื่อใส่ผิดมากเกินไป
- 14 ภาษา (รวม RTL) สว่าง/มืด ปรับตามหน้าจอ PWA ติดตั้งได้ โหมดสาธิต `#/demo` หน้าเกี่ยวกับ/ข้อกำหนด/ความเป็นส่วนตัว

## เริ่มต้นอย่างรวดเร็ว

```bash
npm install
npm run dev            # http://localhost:5173
```

หากใช้งานจริง ให้สร้าง Google OAuth client ของคุณเอง (ราว 5 นาที): docs/GOOGLE_SETUP.md เปิด `#/demo` เพื่อดูตัวอย่างโดยไม่ต้องตั้งค่า

## Docker

```bash
cp .env.example .env
docker compose up -d --build   # http://localhost:8088
```

- สร้างและรันด้วยคำสั่งด้านบน เปลี่ยนพอร์ตด้วย `SPECACT_PORT` ใน `.env`
- nginx แบบไม่ใช้ root ระบบไฟล์อ่านอย่างเดียว CSP เข้มงวด แก้ `.env` แล้วรัน `docker compose up -d` โดยไม่ต้องบิลด์ใหม่
- ใช้ HTTPS กับโดเมนจริง (Google อนุญาต `http://` เฉพาะ localhost และ WebCrypto ต้องใช้บริบทที่ปลอดภัย)
- การตั้งค่าทั้งหมดอธิบายไว้ใน `.env.example` ห้ามใส่ Google client secret ใน `.env`

## ข้อจำกัดที่ทราบ

- ตรรกะ Drive ทดสอบกับ Drive จำลอง ไม่ใช่ Google จริง — ลองกับบัญชีทดลองก่อน
- ในโหมด Testing refresh token ของ Google หมดอายุใน 7 วัน (ล็อกอินใหม่)
- ผู้แสดงความเห็นแก้ความเห็นคนอื่นผ่าน Drive ได้ในทางเทคนิค และการเขียนพร้อมกันอาจทับกันได้ยาก
- การเพิกถอนสิทธิ์ลบสิ่งที่เห็นไปแล้วไม่ได้ ความแข็งแรงของรหัสผ่านขึ้นกับตัวรหัสผ่าน
