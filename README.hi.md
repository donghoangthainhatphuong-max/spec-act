SPECACT एक Vue 3 PWA है जिससे आप पोस्ट और फ़ोटो **सिर्फ़ उन लोगों से साझा करते हैं जिन्हें आप चुनते हैं**। हमारा कोई सर्वर या डेटाबेस नहीं है:

- सारा डेटा **आपके अपने Google Drive के `SPECACT` फ़ोल्डर** में रहता है।
- पोस्ट कौन देख सकता है यह **Google Drive की अनुमतियाँ** तय करती हैं — अनुमति नहीं तो पहुँच नहीं, लिंक होने पर भी।
- लोड होने के बाद ब्राउज़र **सिर्फ़ Google से बात करता है** (CSP बाक़ी सब रोकता है)। वेब होस्ट केवल स्थिर फ़ाइलें देता है।
- हर उपयोगकर्ता **अपना Google OAuth क्लाइंट** लाता है; क्लाइंट ID/सीक्रेट, टोकन और कुंजियाँ डिवाइस से बाहर नहीं जातीं, **दोहरे एन्क्रिप्टेड** हैं और **6 अंकों के PIN** से सुरक्षित हैं।

## निजी · संप्रभु · विकेंद्रीकृत

- डेटा संप्रभुता: डेटा आपके Drive में है, बीच में कोई प्रदाता नहीं — प्रोजेक्ट का कोई सर्वर उसे न रख सकता है, न पढ़ सकता है, न बदल सकता है।
- निजीकरण: कौन देखे, कौन टिप्पणी करे, कौन-सी पोस्ट पासवर्ड वाली या लिंक से सार्वजनिक हो — यह आप तय करते हैं।
- विकेंद्रीकरण: खुला डेटा फ़ॉर्मैट कई वेबसाइट और ऐप को आपका एक ही निजी डेटा स्रोत साझा करने देता है।

## सुविधाएँ

- पोस्ट: बनाएँ, संपादित करें, हटाएँ; फ़ोटो (आकार घटाना, EXIF/GPS हटाना) और स्लाइड व्यूअर (ज़ूम, घुमाना)।
- साझा करना: `@ईमेल` से उल्लेख, भूमिकाएँ “देख सकते हैं”/“टिप्पणी कर सकते हैं”, कभी भी रद्द करें।
- सार्वजनिक लिंक: “लिंक वाला कोई भी” केवल पोस्ट की फ़ाइलें खोलता है, फ़ोल्डर कभी नहीं।
- पासवर्ड वाली पोस्ट ब्राउज़र में एन्क्रिप्ट होती हैं (AES-256-GCM)।
- टिप्पणी मोड: खुला / केवल साझा लोग / लॉक — Drive में लागू। लाइक उन्हीं के लिए जो पोस्ट देख सकते हैं।
- एन्क्रिप्टेड लोकल कैश के साथ तेज़ निजी इंडेक्स (index.json)।
- दोहरे एन्क्रिप्शन वाली लोकल तिजोरी, 6 अंकों का PIN, ऑटो-लॉक, बहुत गलत प्रयासों पर मिटाना।
- 14 भाषाएँ (RTL सहित), लाइट/डार्क, रिस्पॉन्सिव, इंस्टॉल योग्य PWA, `#/demo` डेमो, परिचय/शर्तें/गोपनीयता पेज।

## त्वरित शुरुआत

```bash
npm install
npm run dev            # http://localhost:5173
```

वास्तविक उपयोग के लिए अपना Google OAuth क्लाइंट बनाएँ (लगभग 5 मिनट): docs/GOOGLE_SETUP.md। बिना सेटअप के झलक के लिए `#/demo` खोलें।

## Docker

```bash
cp .env.example .env
docker compose up -d --build   # http://localhost:8088
```

- ऊपर की कमांड से बिल्ड और चलाएँ; पोर्ट `.env` के `SPECACT_PORT` से बदलें।
- बिना root का nginx, रीड-ओनली फ़ाइलसिस्टम, सख़्त CSP। `.env` बदलकर `docker compose up -d` चलाएँ — दोबारा बिल्ड नहीं।
- असली डोमेन पर HTTPS इस्तेमाल करें (Google `http://` सिर्फ़ localhost पर मानता है; WebCrypto को सुरक्षित संदर्भ चाहिए)।
- सभी सेटिंग `.env.example` में दर्ज हैं। Google क्लाइंट सीक्रेट कभी `.env` में न रखें।

## ज्ञात सीमाएँ

- Drive का तर्क असली Google पर नहीं, नकली Drive पर परखा गया है — पहले एक अस्थायी खाते से आज़माएँ।
- Testing मोड में Google रिफ़्रेश टोकन 7 दिन में समाप्त हो जाते हैं (दोबारा साइन इन करें)।
- टिप्पणीकार तकनीकी रूप से Drive के ज़रिए दूसरों की टिप्पणियाँ बदल सकते हैं; एक साथ लिखने पर कभी-कभी एक-दूसरे को ओवरराइट कर सकते हैं।
- पहुँच रद्द करने से देखी जा चुकी चीज़ वापस नहीं होती; पासवर्ड सुरक्षा उतनी ही मज़बूत है जितना पासवर्ड।
